Novel Work 是本机桌面写作台：世界观、人物、文风、剧情都挂在结构树上。 生成章节时，这些卡是硬约束，不是可选参考。

写长篇时，约束比灵感更值钱。

模型很会写「像小说的句子」。Novel Work 要的是：人设不漂、专名不乱、文风不另起、章与章接得上。

结构树工作台

根、分卷、章节排在一张画布上。人物、剧情、知识卡挂到节点上，写哪一章就继承哪一层。

世界观扇形

六张固定槽位：法则、地理、权力、存在、信息、历史文化，外加故事规则。生成必须服从功能选项。

结构化人物卡

世界位置、锚点、关系、信念、深层动机、声线与肢体语言。写章注入的是 formatted 全文，不是一句性格标签。

知识卡硬约束

文风、用词、禁用词、专名替换挂到根，就是全书写作规则。公共库只供提炼，树上的卡才约束正文。

全局 Chat 写章

「生成第 N 章 / 精修第 N 章」走 Chat。先读全书与章快照，按细纲扩写，字数、出场、剧情顺序可自检。

本地知识库

导入 txt / epub / 网页，本地分段与 MiniLM 检索。密钥加密存在本机，不把全书当设定源灌进提示词。

从开书到一章正文

不必先写设定文档。树就是设定，Chat 是笔。

01 开一本新书

定题材、玩法、风格、受众和每章字数。这些标签会约束后面的世界观。

02 生成世界观

一键挂上六张扇形卡和故事规则。可以手改，也可以按槽位用 Chat 补全。

03 挂上会写的卡

人物、进行中的剧情、文风或设定知识卡。挂在根上，后面每章都继承。

04 Chat 生成章节

先有简纲和细纲，再说「生成第 N 章」。精修只改旧稿，不另起炉灶。

MCP

同一棵树，给应用内 Chat，也给 Cursor。

本机 Streamable HTTP（默认 127.0.0.1:17832/mcp）。读写小说、章节、人物、知识卡与公共库，字段和写作注入同形。 树上改了，工作台会刷新。
